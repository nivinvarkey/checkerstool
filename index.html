Quick User Guide

Short instructions for the tasks users actually perform. Administration steps are grouped separately.

Getting started
  1. Open Checker’s Tool and sign in.
  2. Select the applicable job.
  3. Open the module you need from navigation.
Search a spool or Line ID
  1. Open the job’s JDE checking screen.
  2. Enter the spool number, barcode, or Line ID.
  3. Select the matching row and review status, Hold Code, and drawing details.
Open PDF drawings
  1. Search the spool in the selected job.
  2. Choose the matching PDF document.
  3. If necessary, use Refresh or Rebuild PDF Indexes to update local results.
Open GO-BY and instructions
  1. Select a matching JDE row.
  2. Click GO-BY / Instructions.
  3. Review the automatically matched specification and any project instructions; use zoom or maximize if needed.
My Spools
  1. Open My Spools.
  2. Review your assigned records, current status, and aging.
  3. Use the available filters to find outstanding work.
Report a problem
  1. Open the issue reporting or ticket option.
  2. Describe the affected job, spool, and problem.
  3. Submit the ticket for review.
Profile
  1. Open My Profile.
  2. Update the available personal display fields.
  3. Save your changes.
For administrators
  1. Use Admin Center → Projects for supported job management.
  2. Use GO-BY / Instructions to manage document paths and project/spec instructions.
  3. Use other Admin Center sections for user access and central settings.
